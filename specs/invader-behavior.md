# Invader Behavior

## Overview

A grid of invaders marches across and down the screen and fires back at the player.

## User Stories

- As a player, I want invaders to advance and speed up so that the game gets tense.

## Requirements

- [ ] 5 rows x 11 columns of invaders with 3 visual types (by row)
- [ ] Grid moves horizontally, drops one step and reverses at screen edges
- [ ] Movement speed increases as invaders are destroyed
- [ ] Invaders fire bullets downward at random intervals, from the lowest invader in a column
- [ ] Invaders reaching the player's row ends the game

## Acceptance Criteria

- [ ] Unit tests cover edge reversal, descent, speed-up, and firing column selection

## Out of Scope

- Mystery UFO ship
